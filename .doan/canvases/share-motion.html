공유하면 친구가 캐릭터를 바로 보고, 완성·공유받은 캐릭터가 움직이게 · 시안 v0.1 · 2026.11.13

구현됨 03·04·M1~M3 화면과 모션은 코드에 반영했어요 (src/screens/Share.tsx · CardView.tsx · server/). 2단계는 B(미리보기 서버)로 진행했어요.
캐릭터를 콕 눌러보세요 — 반응해요. 「01 모션 가이드」의 모션 줄이기 스위치로 캔버스 전체를 정지 화면으로 볼 수 있어요.

진단

공유가 '잘 안 되는' 이유

지금 코드(src/app/link.ts · src/screens/Share.tsx · index.html)를 읽고 찾은 거예요. 「확인」 표시는 실제 휴대폰에서 한 번 더 봐야 해요.

지금 무엇이 안 되나
  1. 핵심

    링크 미리보기에 캐릭터가 없어요

    공유 링크가 #/card/<코드> 해시 방식이에요. 메신저가 미리보기를 만들 때 # 뒤는 서버로 가지 않아서 카드마다 다른 그림을 줄 수 없어요. 게다가 index.html에 og:image가 없어 제목만 나오거나 비어 있어요. (C안 시안의 '링크 미리보기 예시'는 아직 구현 전)

  2. 핵심

    카카오톡 버튼은 글+링크만 보내요

    공유 시트에 이미지 파일이 들어가지 않아서 채팅방에서는 캐릭터가 보이지 않아요. 친구가 링크를 눌러야만 볼 수 있어요.

  3. 확인

    인스타 스토리가 실패할 수 있어요

    탭 → 이미지 만들기(폰트 로딩 + 캔버스, 기다림) → 공유 시트 순서예요. iOS Safari는 탭 직후가 아니면 공유를 막을 수 있어서 '앗, 잠깐 문제가 생겼어요'가 뜰 수 있어요.

  4. 환경

    HTTPS가 아니면 공유·복사가 꺼져요

    휴대폰에서 http://192.168…:5173으로 열면 공유 시트와 클립보드를 쓸 수 없어 '복사하지 못했어요'로 끝나요. 개발 서버에서 복사한 링크는 localhost라 친구가 열 수 없어요. 저장소에 아직 배포 설정이 없어요.

  5. 작음

    링크가 너무 길어요 (약 500자)

    캐릭터 값 15개를 JSON + base64로 통째로 담아서, 채팅창에 긴 문자열로 보여요.

1단계 · 서버 없이 지금 바로먼저 추천
  • 카드 이미지 + 링크를 같이 보내기공유 시트에 PNG 파일과 링크를 함께 넣어요. 파일을 못 받는 앱이면 링크만 보내요.
  • 이미지는 미리 만들어 두기공유 화면에 들어오면 바로 그려 두고, 탭하면 기다림 없이 공유 시트를 열어요. (iOS 차단 해결)
  • 짧은 링크값 대신 목록 번호로 담아 #/c/2f3a9k… 40자 안팎. 예전 #/card/ 링크도 계속 열려요.
  • 기본 미리보기 태그og:title · og:description · og:image(대표 그림 1장) → 적어도 그림이 있는 미리보기

2단계 · 카드마다 다른 미리보기배포 필요
A카카오 공유 SDK

카드 이미지를 카카오에 올리고 피드 메시지로 보내요. 말풍선에 캐릭터 + [카드 보기] [나도 만들기] 버튼.

필요: 카카오 디벨로퍼스 앱 키 · 사이트 도메인 등록 · 카톡 전용

필요: Vercel · Cloudflare 같은 함수 호스팅 (GitHub Pages는 불가)

추천: 1단계 → B. 카톡 버튼 체감을 더 올리고 싶으면 A를 더해요.

모션

캐릭터가 움직이는 규칙

모든 캐릭터는 숨쉬기 + 눈 깜빡임을 하고, 그 위에 기분마다 시그니처 모션이 하나씩 붙어요. 캐릭터를 누르면 폴짝 반응해요.

11칸씩, 끊어서

이동은 언제나 스테이지 1칸(80×80 격자) 단위. 부드럽게 미끄러지지 않고 뚝뚝 — 픽셀이 번지지 않아요.

2그림자는 바닥에

배경+그림자 / 하체 / 상체 / 이펙트 4겹. 점프해도 그림자는 남고, 숨쉴 땐 상체만 1칸 내려가요.

3기본 + 기분 하나

숨쉬기 1.6초 · 깜빡임 3.2초마다 0.13초는 공통. 기분 모션은 하나만, 2~4초 주기로 은은하게.

4모션 줄이기 존중

기기에서 '동작 줄이기'를 켰다면 정지 그림, 등장 연출은 생략. 저장 이미지(PNG)는 늘 정지 컷이에요.
