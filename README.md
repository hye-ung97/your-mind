# your mind

오늘 기분을 닮은 픽셀 캐릭터를 꾸미고, 카드 한 장으로 공유하는 웹앱이에요.
화면 디자인은 `.doan/canvases/mood-maker-c.html` (C안), 공유·모션은 `.doan/canvases/share-motion.html` 을 따라요.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (/og/<코드>.png 미리보기 그림도 나와요)
npm test           # 단위 테스트 (vitest)
npm run build      # 타입 검사 + 화면(dist/) + 서버(dist-server/) 빌드
npm start          # 배포 서버 실행 (기본 포트 3000)
```

## 흐름

랜딩 → 캐릭터 고르기 → 기분 고르기 → 꾸미기 → 완성 & 공유

- 홈(로고)·친구 카드의 '나도 만들기'·공유 화면의 '처음부터 새로 만들기'는 언제나 캐릭터 고르기부터 시작해요. 고른 캐릭터의 기본 코디와 새 기록으로 초기화돼요.
- 화면 주소는 해시 라우팅이에요: `#/`, `#/start`, `#/mood`, `#/edit`, `#/share`, `#/card/<코드>`
- 공유 링크만 경로예요: `/c/<코드>`. 해시(#) 뒤는 서버로 오지 않아서, 카드마다 다른 링크 미리보기를 만들려면 경로여야 해요.

## 공유

- 저장: 서버 없이 브라우저 `localStorage`(`your-mind:v1`)에만 저장해요. 카드 내용은 링크 안에 담겨요 (서버 DB 없음).
- 링크 코드 v2: 값 대신 파츠 표 안의 순서 번호를 담아 짧아요 (메모가 없으면 40자 안 돼요). 예전 `#/card/eyJ…` 링크도 계속 열려요.
  - ⚠ `src/pixel/avatar.js` · `scene.js` 의 파츠·색·배경 표는 **끝에만 추가**해주세요. 순서를 바꾸면 이미 보낸 링크가 다른 모습으로 열려요 (`model.test.ts` 의 고정 코드 테스트가 지켜줘요).
- 친구에게 보내기: 휴대폰은 공유 시트(카카오톡 등), PC 는 링크 복사. 링크만 보내도 채팅방 미리보기에 그 카드 그림이 떠요.
- 링크 미리보기: 서버가 `/c/<코드>` 페이지에 og 태그를 넣고, `/og/<코드>.png`(1200×630)를 그려줘요. 한글은 `galmuri` 패키지의 BDF 비트맵 글꼴로 찍어요 (네이티브 모듈 없음).
- 미리보기 제목·설명 문구: `src/app/shareCopy.ts`
- 인스타그램 스토리: 준비 중 (Coming soon)

## 모션

- 완성 화면·받은 카드의 캐릭터는 숨쉬기·깜빡임 + 기분별 시그니처 모션을 해요. 누르면 폴짝.
- 받은 카드는 처음 열 때 편지 도착 연출(2.4초)이 나와요. 누르면 건너뛰고, 같은 탭에서 다시 열면 생략해요.
- 기기에서 '동작 줄이기'를 켜면 정지 화면이에요. 이미지 저장(PNG)은 언제나 정지 컷이에요.

## 배포 (Coolify)

1. 새 리소스 → 이 Git 저장소 → **Build Pack: Dockerfile**
2. **Ports Exposes: 3000**, 도메인 연결 (HTTPS — 공유 시트·클립보드는 HTTPS 에서만 동작해요)
3. 환경 변수 **`PUBLIC_URL=https://<도메인>`** — 미리보기 태그에 들어가는 절대 주소예요. 없으면 프록시 헤더로 추정해요.
4. (선택) Health Check 경로 `/healthz`

배포 후 확인: `https://<도메인>/c/<코드>` 의 og 태그를 [카카오 공유 디버거](https://developers.kakao.com/tool/debugger/sharing)로 보면 미리보기를 바로 확인하고 캐시도 지울 수 있어요.
