# your mind

오늘 기분을 닮은 픽셀 캐릭터를 꾸미고, 카드 한 장으로 공유하는 웹앱이에요.
디자인은 `.doan/canvases/mood-maker-c.html` (C안) 을 따라요.

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm test           # 단위 테스트 (vitest)
npm run build      # 타입 검사 + 배포용 빌드 (dist/)
```

## 흐름

랜딩 → 캐릭터 고르기 → 기분 고르기 → 꾸미기 → 완성 & 공유

- 홈(로고)·친구 카드의 '나도 만들기'·공유 화면의 '처음부터 새로 만들기'는 언제나 캐릭터 고르기부터 시작해요. 고른 캐릭터의 기본 코디와 새 기록으로 초기화돼요.
주소는 해시 라우팅이에요: `#/`, `#/start`, `#/mood`, `#/edit`, `#/share`, `#/card/<코드>`

- 저장: 서버 없이 브라우저 `localStorage`(`your-mind:v1`)에만 저장해요.
- 공유 링크: 카드 내용(캐릭터·기분·메모·날짜)을 주소 안에 담아요. 링크를 열면 값을 검사한 뒤 카드를 보여줘요.
- 이미지 저장: 캔버스로 스토리(1080×1920) / 정사각형(1080×1080) PNG 를 만들어요.
- 인스타그램·카카오톡: 휴대폰의 공유 시트(Web Share API)를 써요. 지원하지 않는 브라우저에선 이미지 저장 / 링크 복사로 대신해요.

## 구조

| 경로 | 내용 |
| --- | --- |
| `src/pixel/` | 캐릭터·배경·아이콘 그리기 엔진. 캔버스의 `.doan/assets/pixel-*.js` 를 ES 모듈로 옮긴 것이라, 그림을 바꿀 땐 두 곳을 같이 맞춰주세요. |
| `src/app/` | 기분 데이터·저장·값 검사(`model.ts`), 공유 링크(`link.ts`), 카드 이미지(`cardImage.ts`) |
| `src/components/` | 픽셀 아트·아이콘·하트·별·상단 바·창, 기분 카드 |
| `src/screens/` | 화면 6개 |
| `src/styles.css` | 캔버스의 색·컴포넌트 CSS + 반응형 배치 (900px 이하는 모바일 시안 M1~M4) |
